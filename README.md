# Hospital Management System - Object-Oriented Analysis & Design

## Project Overview
This repository contains the Object-Oriented Analysis and Design (OOAD) deliverables for the **Hospital Management System (HMS)** assignment at Kigali Independent University (ULK).

The design focuses on structuring five core classes to manage hospital operations efficiently:
* **Patient**: Manages patient demographic profiles and medical histories.
* **Doctor**: Tracks medical staff specializations and availability.
* **Appointment**: Coordinates scheduling between doctors and patients.
* **Department**: Handles administrative divisions within the hospital.
* **Bill**: Manages billing, payments, and financial accounting.
